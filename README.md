# Четыре клетки

Монохромный тетрис для телефона и компьютера. Семь фигур строго из четырёх
клеток, без рекламы, аналитики, аккаунтов и внешних библиотек. Рекорд хранится
на устройстве. После сохранения файлов браузером игра работает без интернета.

## На iPhone

1. Открой опубликованную игру в Safari.
2. Нажми «Поделиться» → «На экран “Домой”». Если есть переключатель
   «Открывать как веб-приложение», включи его.
3. Открой игру с новой иконки при включённом интернете.
4. Дождись надписи «Готово без интернета», затем проверь запуск в авиарежиме.

Для первой загрузки нужен интернет. Если система удалит данные приложения,
понадобится повторное открытие с интернетом; очистка данных также удаляет рекорд.
При доступной сети браузер может проверять обновления приложения.

## Управление

- ← и → — движение, можно удерживать.
- ↻ или ↑ на клавиатуре — поворот.
- «Ускорить» или ↓ — быстрое падение, можно удерживать.
- «Опустить» или пробел — сразу закрепить фигуру внизу.
- «Пауза» или Esc — пауза; при уходе из приложения игра также встаёт на паузу.

Через каждые 10 линий скорость увеличивается. За 1/2/3/4 линии начисляется
100/300/500/800 очков × текущий уровень. Ускорение даёт 1 очко за клетку,
мгновенный сброс — 2. Текущая партия не сохраняется при полном закрытии игры.

## GitHub Pages

Файлы готового пакета размещаются в корне открытого репозитория. В его настройках:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.
Ориентируйся на адрес сайта, который покажет GitHub. Собственный домен не нужен.

Документация: [настройка GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Разработка

В опубликованном репозитории исходники HTML, CSS и JavaScript лежат рядом.
Никакой сборки и установки зависимостей не требуется. Для локальной проверки
нужен Node.js 20 или новее:

```sh
npm test
npm run dev
```

Адрес локальной проверки: `http://127.0.0.1:4178/four-cells/`.
В рабочей папке до упаковки исходники находятся в `dist`, тесты — в `tests`.
`Package.ps1` создаёт отдельную папку `github` и переносимый архив для публикации.
При изменении файлов игры увеличивай версию кэша в `sw.js`.
Для офлайн-режима на телефоне требуется HTTPS; localhost работает для разработки.
